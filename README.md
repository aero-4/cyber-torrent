# CyberTorrent 🎮

**CyberTorrent** — это приложение, в котором найдется любая игра. Проект обеспечивает быстрый поиск и удобный доступ к игровому контенту, опираясь на современный, надежный и асинхронный стек
технологий.

---

## 🛠 Стек технологий

* **Язык программирования:** Python 3.12
* **API & Шаблонизация:** FastAPI + Jinja2
* **База данных:** PostgreSQL
* **ORM:** SQLAlchemy
* **Миграции:** Alembic
* **Кэширование:** Redis
* **Брокер задач:** RabbitMQ + Taskiq
* **Аутентификация:** JWT (с использованием JOSE)

---

## 📋 Предварительные требования

Перед началом работы убедитесь, что на вашем компьютере установлены:

* **Git** (для клонирования репозитория)
* **Docker** и плагин **Docker Compose**

---

### 🐧 Инструкция по установке

1. Скачивание проекта

```bash
git clone https://github.com/aero-4/cyber-torrent.git
cd cyber-torrent
```

2. Запуск приложения

```bash
docker compose up -d
```
